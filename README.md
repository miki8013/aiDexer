# aiDexer

Find the right AI tool for your task.

## Usage

Run the app and use the search box to get tool recommendations.

## Development

```bash
npm install
npm run dev
```

## Environment

Create a `.env` file with your Groq API key:

```
GROQ_API_KEY=your_key_here
```

## Deploy

This project is configured for Vercel. Import the repo and add the `GROQ_API_KEY` environment variable.
